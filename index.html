OBS Studio Plugin

PowerPoint Presentations Plugin for OBS

This plugin automatically converts a PowerPoint presentation into images, eliminating the need for you to do it manually.

Requirements: You must have PowerPoint installed. You do not need to open the application every time you use the plugin; having it installed is sufficient.

Instructions: Copy the files: obs-powerpoint-slides.dll , obs-powerpoint-slides.pdb
and paste them into the following folder: C:\Program Files\obs-studio\bin\64bit
